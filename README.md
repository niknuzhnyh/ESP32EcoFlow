# ESP32 DevKit V1 (ESP-WROOM-32) Power Grid Monitor

Професійна автономна система моніторингу наявності мережевої напруги (220V через 5V USB-адаптер) на базі надійного мікроконтролера **DOIT ESP32 DevKit V1 (модуль ESP-WROOM-32, чіп CP2102)**. 

Система розрахована на безперебійну роботу **24/7**: підтримує сповіщення через **Signal REST API**, логування в **Google Sheets** (Google Apps Script Webhook), локальний вебінтерфейс конфігурації, **Captive Portal** для первинного налаштування Wi-Fi та **OTA-оновлення** прошивки по повітрю.

---

## ⚡ Апаратна архітектура та підключення (ESP32 DevKit V1)

### 1. Живлення мікроконтролера
ESP32 DevKit V1 живиться через штатний роз'єм Micro-USB від **зовнішнього Powerbank** (або модуля безперебійного живлення UPS 5V), що забезпечує безперебійну роботу контролера під час блекаутів.
Потужний вбудований стабілізатор **AMS1117-3.3V** (до 1000 мА) гарантує стабільну роботу радіотракту Wi-Fi без просідань напруги.

### 2. Вхід моніторингу мережі (Пін D4 / GPIO 4)
Зовнішній блок живлення 5V (USB-зарядка, підключена до розетки 220V) підключається до входу контролера через один із двох варіантів:

#### Варіант А: Резистивний подільник напруги зі світлодіодом розряду (Рекомендований)
```
[Мережевий 5V USB] ──┬──────────────── [10 кОм] ──┬─── Пін D4 / GPIO 4 (ESP32)
                     │                            │
                 [ 1 кОм ]                    [15 кОм]
                     │                            │
                 [ Анод (+) LED ]                 │
                 [ Катод (-) LED ]                │
                     │                            │
[Мережевий GND]    ──┴────────────────────────────┴─── Пін GND (ESP32)
```

* **Розрахунок напруги на піні D4:** $V_{GPIO} = 5.0\text{V} \times \frac{15}{10 + 15} = 3.0\text{V}$ (безпечно для входу 3.3V).
* **Світлодіод з резистором 1 кОм (Bleeder circuit):**
  1. *Миттєвий розряд конденсаторів зарядки:* вихідні фільтруючі ємності 5V зарядки (470–1000 мкФ) без навантаження розряджаються до 30 секунд. Світлодіод розряджає їх за частки секунди, забезпечуючи миттєву фіксацію $T = 0$.
  2. *Візуальний контроль:* індикатор світиться, коли блок 5V фізично видає напругу.
* **⚠️ Спільна земля (GND):** мінус (GND) від мережевої 5V зарядки та пін **GND** плати ESP32 **обов'язково** мають бути надійно з'єднані між собою!

#### Варіант Б: Опторозв'язка (PC817 / EL817) — повна гальванічна ізоляція
```
[Мережевий 5V USB] --- [ 1 кОм ] ---> [ Анод (1)   PC817   Колектор (4) ] ---> Пін D4 (ESP32)
[Мережевий GND]    -----------------> [ Катод (2)          Емітер (3)   ] ---> Пін GND (ESP32)
```
* *Примітка:* При використанні оптопари при наявності 5V вхід GPIO 4 притягується до GND. У веб-інтерфейсі увімкніть опцію **"Інвертований вхід (оптопара)"**.

### 3. Світлодіодна індикація (Вбудований синій LED на піні D2 / GPIO 2)
На платі ESP32 DevKit V1 використовується вбудований синій світлодіод на піні **D2**:
- 💡 **Світиться безперервно:** Напруга 5V є, мережа стабільна, Wi-Fi підключено.
- ⏳ **Повільне блимання (1 сек: 500мс увімкнено / 500мс вимкнено):** Світло зникло ($T=0$), триває відлік таймера 10 хвилин.
- 🚨 **Швидке тривожне блимання (250 мс: 4 рази на сек):** Світла немає понад 10 хвилин (активна тривога $T=10$ хв).
- 📶 **Часте блимання (500 мс):** Підключення до домашнього Wi-Fi роутера.
- 📡 **Короткі імпульси-маяки (1 раз на сек):** Режим точки доступу (SoftAP `PowerMonitor-Setup` / Captive Portal).
- ⚡ **Короткий спалах (250 мс):** Відправка HTTP-запиту (Signal / Google Sheets).

## 🌐 Мережеві сервіси та Web UI

1. **Captive Portal / Wi-Fi Manager:**
   - Якщо Wi-Fi не налаштований або домашній роутер недоступний, ESP32 автоматично піднімає точку доступу **`PowerMonitor-Setup`** (IP: `192.168.4.1`).
   - При підключенні зі смартфона автоматично відкривається сторінка налаштувань (DNS Redirect).
2. **mDNS (Bonjour):**
   - У домашній мережі пристрій доступний за ім'ям: **`http://power-monitor.local`** (або за його локальною IP-адресою).
3. **Web-інтерфейс:**
   - **Dashboard:** відображення поточного стану живлення в реальному часі, таймер тривалості відключення, зворотний відлік до тривоги 10 хв, RSSI, вільна пам'ять, журнал відправлених сповіщень.
   - **Налаштування:** конфігурація Wi-Fi, Signal API (`http://<ip>:8080`), Google Sheets Webhook, основного та списку резервних номерів, повне редагування 6 шаблонів сповіщень, калібрування debounce (мс) та таймаутів.
   - **OTA Оновлення:** форма завантаження файлу `.bin` безпосередньо з браузера з відображенням прогресу.

## 📊 Інтеграція з Google Sheets

Пристрій надсилає POST-запити у форматі JSON на Google Apps Script Webhook. У поле `device` автоматично підставляється ім'я пристрою разом з його локальною IP-адресою:
```json
{
  "event": "POWER_LOST_T0",
  "status": "OFF",
  "duration_sec": 0,
  "message": "⚠️ [СВІТЛО ЗНИКЛО]...",
  "device": "power-monitor (192.168.0.104)",
  "uptime_sec": 120
}
```

### Приклад Google Apps Script (`Code.gs`):
```javascript
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    sheet.appendRow([
      new Date(),
      data.device || "ESP32",
      data.event || "",
      data.status || "",
      data.duration_sec || 0,
      data.message || "",
      data.uptime_sec || 0
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({status: "success", message: "Row logged successfully"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", error: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
```

## 💬 Інтеграція з Signal REST API

Система взаємодіє з локальним або віддаленим [signal-cli-rest-api](https://github.com/bbernhard/signal-cli-rest-api) (працює на порту **8080**).
* **URL сервера:** `http://<ip_сервера>:8080`
* **Формат відправки:** POST `/v2/send`
* **Одержувачі:** підтримується відправка на основний номер телефону та список резервних номерів (через кому).

## 🛠️ Збірка, прошивка та моніторинг через PlatformIO

### Прошивка плати ESP32 DevKit V1 по кабелю (COM5):
```bash
# Клонування репозиторію
git clone https://github.com/niknuzhnyh/ESP32EcoFlow.git
cd ESP32EcoFlow

# Збірка прошивки
pio run

# Заливка у підключену плату (COM5)
pio run --target upload

# Моніторинг Serial-порту (115200)
pio run --target monitor
```

### Оновлення по повітрю (OTA):

#### Через веб-інтерфейс:
1. Скомпілюйте прошивку: `pio run`.
2. Відкрийте у браузері [http://power-monitor.local](http://power-monitor.local) (або IP пристрою).
3. Перейдіть на вкладку **"Оновлення (OTA)"**, оберіть файл `.pio/build/esp32-devkit-v1/firmware.bin` та натисніть **"Почати прошивку"**.

#### Через термінал (однією командою):
```bash
curl -F "update=@.pio/build/esp32-devkit-v1/firmware.bin" http://power-monitor.local/update
```
